# 抖音知识库 · 离线部署说明

适用于目标电脑**不能联网**（或网速很差）的场景：在一台能联网的电脑上准备好
模型与浏览器，拷贝到目标电脑，让应用直接复用，跳过首次运行时的下载。

## 一、需要拷贝什么

| 内容 | 大小 | 用途 | 是否必需 |
| --- | --- | --- | --- |
| 语音模型（3 个） | 约 2.0 GB | 本地转写 | 必需 |
| Playwright Chromium | 约 150 MB | 下载抖音视频 | 必需（否则无法下载视频） |
| CUDA 版 PyTorch | 约 2.5 GB | GPU 加速转写 | 仅 GPU 需要（CPU 版已内置在安装包） |

## 二、在「能联网」的电脑上：找到并拷贝模型

### 1. 模型的标准结构

语音模型是 ModelScope 的缓存，所需 3 个模型固定为：

```text
<某个缓存根>\models\iic\
├── speech_paraformer-large-vad-punc_asr_nat-zh-cn-16k-common-vocab8404-pytorch\   （约 867 MB）
├── speech_fsmn_vad_zh-cn-16k-common-pytorch\                                     （约 4 MB）
└── punc_ct-transformer_cn-en-common-vocab471067-large\                           （约 1.1 GB）
```

> 注意 `\models\iic\` 这两层是固定的，缺一层应用就找不到模型。
> GPU 与 CPU 用的是同一套模型，无需分别准备。

### 2. 找到它们（常见位置，任选存在的那个）

- 通过应用「环境准备」下载过：`<安装目录>\runtime\models\models\iic\`
- 本机 ModelScope 默认缓存：`C:\Users\<用户名>\.cache\modelscope\hub\models\iic\`

用 PowerShell 直接打开对应文件夹确认：

```powershell
# 默认缓存位置
explorer "$env:USERPROFILE\.cache\modelscope\hub\models\iic"

# 安装目录（把 <用户名> 换成实际用户名）
explorer "$env:LOCALAPPDATA\Programs\DouyinKnowledgeBase\runtime\models\models\iic"
```

### 3. 拷贝

把整个 **`iic` 文件夹**（连同里面 3 个模型子目录）复制到 U 盘 / 移动硬盘。
建议在移动盘上保留 `models\iic` 两层结构，例如：

```text
D:\DouKB-Models\models\iic\...
```

## 三、在「目标（离线）电脑」上：安装并指定目录

### 方式一：指定离线目录（推荐，模型放哪都行）

1. 正常安装 `DouyinKnowledgeBase-Setup-1.1.0-x64.exe`。
2. 把拷来的文件夹放到目标机任意位置，保持结构，例如 `D:\DouKB-Models\models\iic\...`。
3. 打开应用，在主页点「环境准备」。
4. 在「模型缓存目录」中填写**缓存根目录**（即 `models` 的上一层）：

   ```text
   D:\DouKB-Models
   ```

   也可以填 `D:\DouKB-Models\models`，应用会自动回退到上一层；
   但不要填到 `iic` 或其子目录。
5. 点击「重新自检」：自检清单里的「语音模型」应变为 ✅，并显示 `D:\DouKB-Models`。
6. 点击「开始准备环境」：此时不会再下载模型，只会补齐其它缺失项。

### 方式二：放进安装目录（免配置）

把模型直接放到安装目录下：

```text
<安装目录>\runtime\models\models\iic\...
```

应用会把它当作「内置模型目录」自动复用，无需在界面上指定。
安装目录默认为 `C:\Users\<用户名>\AppData\Local\Programs\DouyinKnowledgeBase`
（若安装时选了别的盘，以实际位置为准）。

## 四、离线使用「下载视频」：拷贝 Playwright 浏览器

模型只解决**转写**；下载抖音视频还需要 Playwright 的 Chromium，安装包未内置，需一并拷贝。

1. 在能联网的电脑上，用**应用自带的内置 Python** 下载（务必用内置 Python，保证浏览器版本与
   playwright 包版本一致）：

   ```powershell
   $app = "$env:LOCALAPPDATA\Programs\DouyinKnowledgeBase"
   $env:PLAYWRIGHT_BROWSERS_PATH = "$app\runtime\browsers"
   & "$app\runtime\python\python.exe" -m playwright install chromium
   ```

   若不设置 `PLAYWRIGHT_BROWSERS_PATH`，浏览器会装到 `%LOCALAPPDATA%\ms-playwright`，
   这种情况下需要手动把它搬到目标机的 `<安装目录>\runtime\browsers`。

2. 把生成的 `runtime\browsers` 整个文件夹拷到目标机的 `<安装目录>\runtime\browsers`。
3. 回到「环境准备」点「重新自检」，「Playwright 浏览器（下载视频）」应显示 ✅。

## 五、GPU（可选）

目标机有 NVIDIA 显卡且想要 GPU 加速时，CUDA 版 PyTorch 需联网下载（约 2.5 GB）。
完全离线时只能选「仅 CPU」（CPU 版已内置在安装包），转写可用但会慢一些。

## 六、常见问题

- **自检里模型一直是 ❌**：确认填的是**缓存根**（其下应有 `models\iic\`），且三个模型子目录
  都在、名称完全一致。
- **模型已拷贝仍提示下载**：多半少了一层目录，正确结构是
  `<你填的目录>\models\iic\<模型名>`。
- **能转写但下载视频失败**：Playwright 浏览器没拷（见第四节）。
- **只想验证、不想触发下载**：在「环境准备」里把设备选「仅 CPU」，点「开始准备环境」；
  模型齐全时会直接跳过下载步骤。
